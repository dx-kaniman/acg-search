# アニマルカードゲーム 検索

「アニマルカードゲーム」（Animal Card Game, ACG）向けの非公式カード検索ツールです。
ブラウザ上で動作し、カード名や効果テキスト、コスト、タイプ、種族などの条件からカードを絞り込むことができます。
データは公式サイト掲載のカードリストをもとに生成された JSON ファイルを使用しています。

> ⚠️ 本ツールはファンメイド（非公式）プロジェクトです。公式運営・開発元とは一切関係ありません。
> ⚠️ 個人利用を目的として作られたツールのため、利用環境によっては正しく動作・表示されない場合があります。
> ⚠️ 予告等なしに仕様が変わることがあります。

## 🧩 主な機能

| 機能          | 説明                                   |
| ----------- | ------------------------------------ |
| 🔍 カード名検索   | 部分一致でカード名・読み仮名を検索                    |
| 📘 効果テキスト検索 | 空白区切りで複数語検索（AND/OR切替可能）              |
| 💎 属性条件     | コスト・ATK・DEF・タイプ・種族・領土条件で絞り込み         |
| 🗺️ 領土条件    | 平・山・水・森・夜・無の個数指定検索、複数属性スロット対応（例：森／夜） |
| 📚 商品横断検索   | 第1弾デッキ〜領土まで複数セットをまとめて検索              |
| 📋 ソート機能    | 名前順、コスト順、ATK/DEF順、商品順、カード番号順をサポート    |
| 🖼️ サムネイル表示 | カード画像を公式サイトへリンク付きで表示                 |
| ⚙️ レスポンシブ対応 | スマホ・PCいずれでも快適に利用可能                   |
| 🧾 種族モーダル設定 | 種族の大量データをモーダルで一括選択／全選択／解除が可能         |

## 🧑‍💻 開発情報

* **HTML/CSS/JSのみで構築**（フレームワーク不使用）
* **完全クライアントサイド動作**（サーバー不要）
* **JSONベース拡張**：新商品追加時はJSONを差し替えるだけで対応
* **主要ライブラリ**：なし（標準ブラウザAPIのみ）
